# Changelog

This project follows [Semantic Versioning](https://semver.org/). Each entry names the Unfold version it targets.

## 1.0.0 (2026-10-31)

**Targets:** django-unfold 0.110.0. **Docs snapshot:** 2026-09-05 (v0.105.0 + 3).

### Added

- `skills/unfold-admin/SKILL.md`: the entry point, with conventions, pitfalls, decision guide, reference index and workflow.
- Twelve task-oriented reference files covering all 76 content pages of the docs snapshot.
- Post-snapshot features verified from the source, each labelled: `JSONSchemaField`, sidebar sub-navigation, card `title_icon` and `description`, and the reversion apps.
- A table of known errors in the official docs examples.
- `docs/coverage.md`: the page inventory, statistics and unresolved items.
- `scripts/validate.py`: frontmatter, size, link, anchor and coverage checks.
